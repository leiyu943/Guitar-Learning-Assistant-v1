# 吉他学习助手：使用教程 / User Guide

## 1. 项目是什么

这是一个本地运行的吉他谱面与音频同步练习工作台。它适合用来：

- 打开一张谱面图片并配套播放音频；
- 观察波形和播放进度；
- 在谱面行之间跟随播放光标；
- 为复杂谱面手动添加音频—谱面配对刻度；
- 点击谱面或波形快速跳到对应时间。

当前版本是开发中的开源预备版，不是完整的 OMR、录音评分或 AI 教练产品。

## 2. 不需要代码：直接运行可执行版

1. 解压发布包。
2. 双击 `start.bat`，或直接运行 `GuitarLearningAssistant/GuitarLearningAssistant.exe`。
3. 第一次运行时请确认 Windows 音频输出设备可用。
4. 在左侧曲库选择一首曲目。
5. 点击“播放示范”，或按空格键播放/暂停。

如果 Windows SmartScreen 提示未知发布者，这是因为当前版本尚未使用商业代码签名证书；请确认文件来自可信发布包后再决定是否运行。

## 3. 界面基本操作

### 播放与定位

- 波形上单击：跳到该音频位置。
- 空格键：播放/暂停。
- 波形横向缩放：拖动 1×–20×滑杆，便于定位细小时间差。
- 谱面上单击：普通模式下跳到对应音频位置。
- 播放时橙色竖线同时显示在波形和谱面上。

### 曲库

- “导入曲目”：选择一个音频文件，再选择一个或多个谱面图片。
- “删除曲目”：删除当前曲目的整个文件夹，包含音频、谱面、MIDI 和刻度数据；删除前会二次确认，此操作不可撤销。
- “重新扫描曲库”：文件夹被外部修改后重新扫描。

### 配对刻度

1. 点击“添加配对刻度”。
2. 在波形上点击音频时间。
3. 在谱面对应位置点击，完成一组配对。
4. 可在任意音频时间添加，不要求按顺序从末尾追加。
5. 点击已有刻度可选中，再点击“删除选中刻度”或按 Delete。
6. “退出标记模式”后，谱面点击恢复普通跳播，不会增加刻度。

配对刻度越准确，跨行播放光标越可靠。没有刻度时，谱面点击采用按行序和横向位置的估算。

## 4. 中英双语

顶部菜单用于切换语言：

- 中文界面显示 `Language`；
- English 界面显示 `语言`。

选择会保存到本机，下次启动继续使用。

## 5. 内置曲目

`songs/` 文件夹中包含测试素材。每个曲目文件夹都有 `info.json`，记录曲名、来源、许可和音频说明。部分 WAV 是由同版 MIDI 合成的测试音频，不代表真人录音。

## 6. 从源码运行

需要 Python 3.11 或兼容版本：

```powershell
python -m pip install -r requirements.txt
python main_window.py
```

运行测试：

```powershell
python -m unittest discover -s tests -v
```

## 7. 常见问题

### 没有声音

检查系统默认输出设备、音量和其他程序是否独占声卡。源码运行时确认 `sounddevice` 已正确安装。

### 曲谱行识别不理想

自动算法依据长横谱线、线距以及五线谱/TAB 结构判断行，不是音乐语义识别。倾斜扫描、断线、双栏、跨页和特殊排版可能需要手动配对刻度。

### 删除后能恢复吗

当前删除是直接删除曲目文件夹，没有回收站。发布前请备份 `songs/`。

### 为什么有些按钮显示“尚未启用”

OMR 音符级识别、录音评分、AI 教练和在线搜索下载尚未完整恢复，这些入口目前只是开发占位。

## 8. 开源发布前检查

- 把 `AUTHOR_EMAIL.txt` 和 `LICENSE` 中的占位邮箱替换成真实邮箱；
- 逐项核查 `songs/` 中第三方素材的许可证和再分发条件；
- 移除本机路径、调试日志和临时文件；
- 运行 `tests`，确认分行、光标、双语和删除功能通过；
- 发布时同时提供 `README.md`、本教程、`requirements.txt` 和可执行版说明。
